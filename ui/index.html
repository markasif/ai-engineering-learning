Concept Explainer
CAG (Cache-Augmented Generation)

CAG avoids chunking and vector search entirely by loading full documents directly into a massive LLM context window (1M+ tokens), pre-computing the KV cache once.

When to use CAG Best for small, fixed doc sets (<50 pages). Zero missed chunks, 100% full-document visibility.
When to use RAG Best for scaling to thousands of pages. Efficient vector search, lower latency, and lower token cost.
